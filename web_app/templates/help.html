Help

Getting Started

Prerequisites:

  1. Create a free account at textbee.dev
  2. Install the Textbee Android app on your phone and link it to your account
  3. Copy your API Key and Device ID from the Textbee dashboard
  4. Enter them in Settings

Run the app: python -m web_app.app then open http://localhost:5000

Send a Message

  1. Go to Send
  2. Choose a recipient — search by name, pick a group, or type a number
  3. Type your message or select a saved Template
  4. Click Send SMS

Contacts

  • Add: Click "Add Contact", fill in name and phone number, optionally a group
  • Edit/Delete: Use the buttons in the contacts table
  • Import CSV: Your CSV must have Name and Phone columns; Group is optional
  • Google Sync: Click "Sync Google Contacts" — you'll be asked to sign in the first time. Contacts are merged by phone number.

Google OAuth setup: You need a Google Cloud project with the People API enabled and an OAuth 2.0 client ID (Desktop app type). Download the credentials JSON and set GOOGLE_CLIENT_SECRET_FILE in Settings.

Templates

  • Go to Templates and click "New Template"
  • Write your message using Markdown — a live preview is shown alongside the editor
  • Templates are selected on the Send page and rendered to plain text before sending

Markdown quick reference: **bold**, *italic*, - list item, blank line = new paragraph

History

Every sent message is logged in History with:

  • sent — message delivered to the Textbee API queue successfully
  • failed — an error occurred; click the row to see the error detail

Note: "sent" means Textbee accepted the request — delivery to the recipient depends on your phone being online.

Settings

  • API Key / Device ID: Found in your Textbee dashboard under "Devices"
  • Test Connection: Sends a ping to the Textbee API to verify credentials
  • Google Account: Connect to enable Google Contacts sync; Disconnect removes the stored token

CLI App

The original sms.py command-line app continues to work independently. Both apps share the same contacts.db database, so contacts added in either app are visible in both.

Run it with: python sms.py
